Mobile App Requirements Document
App Name: ConnectIQ
Tagline: Scan a business card. Never lose the relationship.
1. Product Overview

ConnectIQ is an AI-powered mobile networking assistant that scans business cards, captures meeting context, sends an instant personalized introduction email, reminds users to follow up, and measures the ROI of networking events.

The app is not just a business card scanner. It helps users remember who they met, why the relationship matters, what was discussed, what follow-up is needed, and whether the connection eventually created business value.

3. Core Problem

People collect business cards at events but often fail to:

Remember where they met the person
Recall what was discussed
Follow up on time
Track business opportunities
Measure event ROI
Connect contacts with CRM or email tools
4. Main Product Goals

The app should help users:

Scan and save business card information quickly.
Add meeting context using text, voice, or predefined tags.
Send an instant personalized introduction email to the scanned contact.
Generate an AI-powered relationship summary.
Create follow-up reminders and tasks.
Track networking ROI by event.
Prioritize high-value contacts.
Integrate with email, calendar, CRM, and contacts.

6. Main User Flows
Flow 1: Scan and Send Intro Email
User opens app.
User taps “Scan Card.”
Camera opens.
User scans card.
App extracts details.
User reviews and edits details.
User enters event and meeting context.
AI generates summary and intro email.
User approves email.
Email is sent.
Contact is saved.
Follow-up reminder is created.
Flow 2: Add Contact Manually
User taps “Add Contact.”
User enters contact details.
User adds event and notes.
AI generates relationship summary.
User saves contact.
Flow 3: Follow-Up Reminder
User receives reminder.
User opens contact.
AI suggests follow-up email.
User approves or edits.
Email is sent.
Timeline is updated.
Flow 4: Event ROI Review
User opens Events dashboard.
User selects event.
App shows cards scanned, follow-ups, meetings, proposals, and revenue.
User can export report.

12. Non-Functional Requirements
Performance
Card scan result should appear within 5 seconds.
Contact search should return results instantly.
App should work smoothly on iOS and Android.
Security
Encrypt user data.
Secure email and CRM connections.
Support OAuth login.
Allow users to delete contacts.
Allow users to delete account.
Store business card images securely.
Privacy
Ask user permission before sending emails.
Clearly disclose what data is stored.
Allow users to control AI processing.
Support consent and unsubscribe options where needed.
Reliability
App should save scanned card even if email sending fails.
Failed emails should be retryable.
Offline scan drafts should be saved locally and synced later.
